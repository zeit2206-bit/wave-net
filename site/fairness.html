The test

The usual industry way to speed up a standard network is 8-bit numbers (whole numbers from −127 to 127) instead of 32-bit decimals. We converted the trained 97.3% network to 8-bit and compiled it.

Honest reading

Well-tuned 8-bit libraries usually run 2–4× faster than 32-bit on CPUs. That could tie or beat the gates. So the gates' speed lead is real against the normal network, but probably not against a tuned 8-bit one. We didn't install such a library to settle it.

Verdict: is gate-net better than the standard net? No, not overall.

So were bits the wrong answer?

No. Both networks already run on bits: a standard network just uses 32 bits per number. The real question is how many bits per number. One bit loses too much nuance. The industry's sweet spot is around 2–8 bits, and Microsoft's BitNet (2024) goes down to about 1.6 bits: weights of only −1, 0 or +1. That's the next step.
