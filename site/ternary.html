The middle ground: −1, 0, +1

Keep the neurons (they train well), but give each weight only three possible values.

The idea

Each weight is −1, 0 or +1 (times one shared scale per layer). That's about 1.6 bits per weight. Then "multiply" disappears:

WeightWhat the neuron does with that input
+1add it
−1subtract it
0skip it

Training keeps a normal decimal copy of each weight to nudge, but every guess uses the rounded −1/0/+1 version, so the network learns to work with three values from the start (method from BitNet b1.58, Microsoft, 2024).

Ternary 128 ties the standard network on speed, doing less work (79,000 adds/subtracts vs 118,000 multiply-adds per image), but reading from scattered memory places. The gates are still fastest.

Best all-rounder: ternary 128 — smallest, trains in seconds, 96.5%, same speed as standard.
Keep in mind

None of our versions got the decades of tuning NumPy's matrix library has. With equal tuning, ternary would likely gain the most, because add/subtract/skip fits the CPU's wide instructions well. That's an expectation, not a measurement.
